# Gemeinsame FYLO-Aktionsicons

Die neun mit ImageGen erstellten Original-PNGs liegen gemeinsam unter ui-icons/src/main/res/drawable-nodpi. Beide Android-Apps verwenden dieselben Assets. Die Originaldateien behalten ihren transparenten Hintergrund; zur Anzeige werden kleine Bitmap-Kopien im Arbeitsspeicher dekodiert und gemeinsam gepuffert.

| Icon | Zuordnung |
| --- | --- |
| Haken | Bestätigte Auswahl; im Notizmodul ausdrücklich Notiz speichern |
| X | Abbrechen; im Notizmodul Notiz bzw. Modul schließen |
| Ausrufezeichen | Wichtige Meldungen und Fehler |
| Plus | Screen/Modul hinzufügen; im Notizmodul Anhang hinzufügen |
| Minus | Zuordnung entfernen; im Notizmodul ausgewählten Anhang aus der Notiz entfernen |
| Öffnen / Ordner | Modul/KI-Assistent bzw. Auswahlliste öffnen |
| Löschen / Papierkorb | Leeren Screen löschen; im Notizmodul Notiz löschen |
| Speichern / Diskette | Modul- und KI-Auswahl speichern |
| Schließen / Ausgang | Systemsteuerung schließen |

Die Symbolzuordnung verändert keine vorhandenen Löschsperren, Daten oder Berechtigungen. Die Notiz-Werkzeugleiste verwendet die vom Nutzer ausdrücklich vorgegebene Reihenfolge Haken, Papierkorb, Plus, Minus, X.
